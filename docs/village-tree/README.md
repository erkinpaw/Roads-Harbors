# Древо деревни — локальная копия

Здесь лежит то же древо развития, что и в веб-редакторе
(https://claude.ai/artifact/Foa6rmx6UKBcW1WGSMjt5S). По нему мы сверяемся и моделируем экономику.

| Файл | Что это |
|---|---|
| `tree.json` | Данные v2: ветки, 31 категория склада, 257 конкретных предметов (прилавки), 49 зданий с уровнями и прилавками |
| `tree-v1.json` | Первая версия (241 ресурс) — для сравнения |
| `seed_v2.py` | Как собиралась версия 2 (генератор данных) |
| `index.html` | Тот же редактор, открывается прямо из папки (двойной клик), без интернета |
| `icons.js` | Иконки ресурсов из текстур Minecraft |
| `tree-data.js` | `tree.json` для `index.html` (генерируется, руками не править) |
| `model.py` | Синхронизация и первая модель баланса |

## Как пользоваться
- **Открыть древо:** `index.html`. Правки хранятся в браузере.
- **Перенести правки в проект:**
  1. Вкладка JSON → «Скачать tree.json».
  2. Положить файл сюда, заменив старый.
  3. Запустить `python model.py sync`.
- **Обновить копию после правок на сайте:** попросить Claude выгрузить древо заново (он читает базу страницы и
  перезаписывает `tree.json`).
- **Баланс:**
  - `python model.py balance --level 3` — все здания по одному на 3-м уровне;
  - `python model.py balance --village hut=4,field=3,farm=1,wood_hut=2,sawmill=1 --level 2` — конкретная деревня.

  Скрипт выводит, чего не хватает (кто тратит), что копится (кто делает).

## Как читать данные
- `make` и `use` уровня — количество в день на всё здание.
- `n` — количество, `p` — шанс в процентах (нет поля — каждый день). В среднем в день выходит `n × p / 100`.
- `cost` уровня — разовая стоимость постройки (1-й уровень) или улучшения (2-й, 3-й).
- `unlock` — разовая стоимость открытия узла древа.

## Версия 2: категории и прилавки
- Деревня считает около 30 категорий (`catalog.resources`): Еда, Зерно, Древесина, Доски, Палки, **Столярка**,
  Камень, **Тёсаный камень**, Руда, Металл, Инструменты, Красители, Ткани…
- Конкретные предметы (`items`) есть только на прилавке. Предмет берёт `units` единиц своей категории (`res`).
  Пример: железная кирка — 3 «Инструментов», синяя шерсть — 1 «Ткани».
- Прилавок здания (`sells`) — что продаёт его житель, с какого уровня и сколько в день.
  Лесник продаёт топоры, шахтёр — кирки, художник — краски.
